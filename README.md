## GearX 🏎️

Corrida pseudo-3D no estilo do Top Gear (Super Nintendo) para o console **Lupi**: de 1 a 3 jogadores em tela dividida, 5 pistas pelo litoral, do amanhecer à noite de lua cheia, com nitro e pilotos controlados pelo computador.

Comece pelo arquivo `game.lua`, função `update`. A estrada é desenhada em `render.lua`; as pistas ficam em `pistas.lua`. Na pasta `img` estão os gráficos no formato entendido pelo compilador da plataforma.

> Documentação do Lupi: <https://lupi.api.br/docs>. Este repositório é um fork do [primeiro-jogo](https://github.com/lupi-org-br/primeiro-jogo).

## Como jogar

| Controle | Na corrida | Nos menus |
|---|---|---|
| Direcional | Virar | Escolher e mudar opções |
| Botão de baixo (B) | Acelerar | Confirmar |
| Botão da direita (A) | Frear | Voltar |
| Outros botões (X, Y, L, R) | Nitro (3 por corrida) | |
